快趣學英文｜GitHub Pages 上載方法

1. 將 ZIP 解壓。
2. 在 GitHub 建立一個新的 repository。
3. 將解壓後所有檔案上載到 repository 最外層；index.html 同 assets 資料夾要放在同一層。
4. 開啟 repository 的 Settings → Pages。
5. 在 Build and deployment 選擇 Deploy from a branch。
6. Branch 選 main，資料夾選 /(root)，然後按 Save。
7. 等候數分鐘，GitHub 會顯示公開網址。

重要：不要只上載 index.html；assets 資料夾及所有 PNG、manifest、service-worker 檔案都要一齊上載。

手機安裝：用 Chrome 開啟 GitHub Pages 網址，按右上角「⋮」→「加到主畫面」或「安裝應用程式」。
